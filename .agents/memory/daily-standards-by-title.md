---
name: Daily standards by title
description: Product rule for creating and assigning daily standards.
---

Daily standards are configured separately for each title, not as one shared norm. Supported titles are Администратор, Лидер, Вице-Губернатор, Депутат, Адвокат, and Лицензер. Assign a daily standard only to active members with the matching effective title. Assign it immediately after the manager saves it; at 00:00 Europe/Moscow, send the previous cycle for review and assign the next cycle.

**Why:** The user explicitly requested a separate norm for each title.

**How to apply:** Keep the standard editor, uniqueness constraint, and daily assignment cycle aligned by title; do not restore global daily assignment.
